# Como acessar?
A seguir estão listadas as instruções para acessar o repositório.

## Navegador de Internet
1° Passo - É necessário ter um navegador como Chrome, Firefox, Safari e etc...

## GitHub e Repositório
1° Passo - Acesse: https://github.com
2° Passo - Crie um conta ou faça login em uma já existente (caso possua uma)
3° Passo - Acesse o repositório: https://github.com/ASilva-Code/Atividade_01.git

## Editor de Código 
1° Passo - É necessário ter o VS Code (editor de código recomendado)
2° Passo - Dentro do VS Code, no terminal, use o comando 'cd' + o nome do local onde você salvará o projeto (use o comando 'ls' pra ter uma lista de locais disponíveis)
3° Passo - Use o comando 'git clone https://github.com/ASilva-Code/Atividade_01.git'
4° Passo - Na opção "File" clique em "Open Folder" e escolha a pasta do projeto no local escolhido anteriormente.
